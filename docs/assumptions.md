# 적용한 가정

- 단일 운영사 큐레이션 도매몰. 다수 판매자의 직접 입점은 제외합니다.
- 샘플 28개 상품과 이미지는 데모 자료이며 실제 규격·원산지·가격을 보증하지 않습니다.
- 샘플은 VAT 포함 과세 상품. 상품 행과 배송그룹별 공급가액을 반올림하고 나머지를 세액으로 기록합니다.
- MOQ와 수량별 공급단가는 SKU별이며 주문 단위 배수로 주문합니다.
- 소량 시작 기준은 SKU MOQ 5개 이하입니다.
- 동일 배송그룹은 하나의 출고지와 배송정책을 공유합니다. 공급처를 기준으로 자동 합배송하지 않습니다.
- 데모 A 배송비 3,000원 / 100,000원 이상 무료, B 3,500원 정액, 무료 그룹 0원. 추가 지역 배송비는 미적용입니다.
- 데모 결제는 즉시 서버 확인되며 결제 대기 예약은 15분 후 만료 대상입니다.
- 사업자번호는 형식만 검사합니다. 공식 인증과 이메일 인증은 미연동입니다.
- 비회원과 승인대기자는 공개 상품만 탐색하며 공급가와 VIP 상품은 서버에서 제외합니다.
- 실제 사업자명·대표자·연락처는 생성하지 않았습니다. 관리자 설정에서 입력합니다.
- 정책은 운영 검토용 초안. 시행 전 전문가 검토와 운영조건 확정이 필요합니다.
- 서버 기본 상품 목록은 20개로 페이지 분리하며 28개 seed에서는 공개 상품 26개, VIP 전용 2개입니다.
- 개발 환경은 Docker PostgreSQL 17을 기본으로 합니다. 현재 PC에는 Docker가 없어 프로젝트 내부 PostgreSQL 17.4 실행기로 검증합니다.
