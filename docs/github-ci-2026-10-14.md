## 저장소 상태

GitHub 기존 main에서 분기한 별도 브랜치로 B2B 소스를 적용했습니다. b2bsite의 기존 Vite 앱 파일은 B2B Next 앱으로 교체됐으며 main과 기존 GitHub Pages는 변경하지 않았습니다. .env.local은 B2B 브랜치에서 제외했습니다. 인증키·로컬 DB·상품 업로드·빌드 파일은 추가하지 않았습니다.

검증 기록만 추가한 후속 문서 커밋은 [skip ci]로 동일 코드 검사를 반복하지 않습니다. 애플리케이션 코드와 실행 설정은 위 검증 커밋과 같습니다.

Sites 등록 및 운영 배포는 아직 수행하지 않았습니다. PostgreSQL 유지 조건에 맞는 외부 운영 DB·HTTP 연결 계층과 Worker 이식이 필요합니다. 상세 진행은 git-github-sites.md에 기록했습니다.
