# 김대표님이 마지막에 설정할 항목

## 필수 사업 운영 정보

- 법적 사업자명, 대표자, 사업자등록번호, 통신판매업 신고번호, 사업장 주소
- 고객센터 이메일·전화·운영시간, 개인정보 담당자
- 실제 상품 사진·규격·원산지·판매 포인트·가격·재고와 자료 사용 허용 범위
- 출고지와 배송그룹, 실제 배송비·무료 기준·지역 추가비·교환·반품 조건
- 검토를 완료한 약관·개인정보 정책과 정책 버전

위 항목은 관리자 /admin/products, /admin/settings, /admin/content에서 입력합니다.

## 서버·보안 설정

- 운영 서버와 도메인, DNS, SITE_URL, HTTPS
- 운영 PostgreSQL DATABASE_URL, DB_PASSWORD, 영속 볼륨
- 새 BETTER_AUTH_SECRET, DEMO_ENABLED=false, APP_ENV=production
- 데모 없는 별도 운영 DB와 새 관리자 계정 (npm run admin:create)
- 비공개 파일 저장소 또는 S3 키·bucket, 상품 이미지 영속 볼륨
- DB·파일 백업·복구 리허설, 예약 만료 스케줄러

## 외부 연동 [blocked]

- 실제 PG 계약·키, 승인·공식 방식 웹훅 검증·환불 구현과 테스트
- 발신 도메인과 이메일 provider, 이메일 인증·재설정 구현
- 공식 사업자 인증 API, 세금계산서·택배조회 provider (필요 시)

키를 입력하는 것만으로 미구현 P1 기능이 완료되는 것은 아닙니다. P0 로컬 데모와 운영 준비 구성은 별개이며 실제 결제는 현재 비활성입니다.
