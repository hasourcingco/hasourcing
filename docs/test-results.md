# 실제 검증 결과

검증일: 2026-10-07, 한국 시간. Windows / Node 24.19.0 / PostgreSQL 17.4 / Chromium. 웹앱은 최종 standalone 배포용 빌드, 설정은 local/demo이며 실제 결제는 없습니다.

| ----------------- | ------------------- | --------------------------------------------------------------------- |
| TypeScript strict | 통과                | tsc --noEmit                                                          |
| ESLint            | 통과                | 오류·경고 없음                                                        |
| Next.js build     | 통과                | 전체 App Router 페이지와 standalone 출력                              |

## 브라우저 검증

- 비회원 HTML/RSC에서 공급가와 VIP 상품 정보 제외, 가격 필터로 보호 가격 추론 차단.
- 승인회원 로그인 → 검색 → 옵션 → 모바일 장바구니 → 배송지 → 데모 주문 → 완료 → 주문조회 → 허용 PDF 다운로드.
- 새로고침 후 장바구니·주문 유지.
- 승인대기자의 구매·관리자 작업·자료 다운로드 차단.
- 일반회원의 VIP 상품과 다른 회원 주문 접근 차단.
- VIP 전용 상품과 적용 VIP 공급가 확인.
- 관리자 상품 생성, 옵션·MOQ·수량 단위·일반/VIP 가격·재고 저장 후 실제 상품 화면 확인.
- 가입 → 관리자 승인·VIP 변경 → 기존 세션 반영 → 이용중지 후 구매와 VIP 목록 노출 차단.
- 견적 접수·관리자 답변·회원 확인, 배송그룹별 송장 저장·주문 상세 반영.
- 관리자 공지 수정 후 고객 화면과 감사 로그 확인.
- 필터 URL·새로고침·빈 검색·품절 구매 차단.
- 수량 단위 오류 안내와 구매 버튼 비활성, 바로 구매의 주문서 이동.
- 390·768·1440px 홈·목록·상세·로그인: 가로 넘침, 깨진 이미지, 브라우저 pageerror/console error 없음.

12개 전체 통과 실행을 확인했습니다. 마지막 권한 보완 이후 전체 실행은 11개 통과, 관리자 테스트 1개는 Windows Chromium의 스크립트 요청 net::ERR_ADDRESS_IN_USE로 실행되지 못했습니다. 같은 최종 서버에서 해당 테스트를 별도 재실행하여 통과했습니다. 테스트 재시도 설정은 0이며 앱 오류를 자동으로 무시하지 않습니다.

## DB·도메인 검증

승인·VIP·관리자 구매 권한 분리, 비공개 가격 null 처리, MOQ·정수 수량·주문 단위·품절·재고 초과, 수량별 단가 경계, VAT 정수 합계, 배송그룹별 합배송·무료 조건을 검증했습니다.

가격 변경 시 주문 재확인, 같은 주문 키의 순차·동시 요청에서 주문 1개 생성, 결제 확인 중복 시 재고 1회 차감, 서로 다른 주문의 동시 재고 예약, 취소 1회 해제, 만료·확인 경쟁, 주문 소유권, DB 승인 상태 재검사를 실제 PostgreSQL에서 확인했습니다. 테스트 데이터의 삭제 범위는 각 통합 테스트가 만든 UUID 데이터에 제한됩니다.

## 실행하지 않은 검증

Docker가 설치되지 않아 Docker 이미지/운영 Compose 실제 실행은 미검증입니다. 운영 배포·TLS 발급·실제 PG 승인/웹훅/환불·메일/S3 외부 통합·운영 백업 복구는 실행하지 않았습니다. 외부 연동 상태는 integrations.md, 마지막 사용자 설정은 production-checklist.md를 확인해주세요.
